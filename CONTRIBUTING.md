# Contributing

Bijdragen zijn welkom onder GNU AGPL-3.0-only. Lees vóór werk aan code [AGENTS.md](AGENTS.md), [architectuur](docs/ARCHITECTURE.md) en [licentiebeleid](docs/REUSE_AND_LICENSES.md).

1. Start met een GitHub Issue.
2. Werk op een nieuwe featurebranch; verander main niet rechtstreeks.
3. Controleer bestaande OSS / built-in frameworkmethoden voordat je custom code schrijft.
4. Vermijd dependencygroei en houd veranderingen beperkt.
5. Noteer upstream bron + licentie wanneer je code hergebruikt; respecteer alle notices.
6. Test, typecheck en build; beschrijf onuitvoerbare checks duidelijk.
7. Maak een PR en merge pas na review.

Geen echte leefstijl- of gezondheidsgegevens, accountgegevens, sleutels, tokenbestanden of .env in issues en PRs. Meld kwetsbaarheden bij voorkeur privé aan de maintainer.
